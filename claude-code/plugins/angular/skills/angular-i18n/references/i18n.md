
# Internacionalización con Transloco

Comprueba en `package.json` el paquete de Transloco instalado (`@jsverse/transloco` en versiones actuales; `@ngneat/transloco` en proyectos antiguos) e importa desde ese paquete.

## Idiomas y scopes del proyecto

Ver el `CLAUDE.md` del proyecto → _Idiomas del portal_ e _Internacionalización — scopes existentes_ para los idiomas disponibles y la lista de scopes activos. Añadir traducciones en **todos** los ficheros de idioma del proyecto.

Si el proyecto dispone del helper `withTranslocoScope()` (en `@utils/shared`), registrar los scopes en rutas con él. **No usar `provideTranslocoScope` directamente en rutas** cuando exista ese helper:

```typescript
withTranslocoScope(['home', 'widgets'], {
  path: '',
  loadComponent: () => import('@pages/home/home/home'),
  title: 'home-title',
});

// Para scopes con alias:
withTranslocoScope({ scope: 'widgets/my-widget', alias: 'myWidget' }, { ... })
```

## Monorepos

- Cada aplicación carga sus ficheros de idioma desde sus propios assets.
- Una librería `feature` con textos propios define su **scope** y aporta sus ficheros; la aplicación que la usa los copia a sus assets (configuración de `assets` del proyecto) o los carga con un loader de scope. Comprueba cómo lo resuelve el proyecto antes de añadir un scope nuevo.
- Las librerías `ui` no fijan textos: los reciben por `input()` o proyección de contenido (ver `library.md`).

## Organización de claves

- **kebab-case** para nombres de clave: `filter-by-category`, `sort-by-date`.
- Agrupar por contexto con objetos anidados:

```json
// ✅ Correcto
{
  "toolbar": {
    "filter-by-category": "Filtrar por categoría",
    "search": "Buscar"
  }
}

// ❌ Evitar — claves planas sin contexto
{ "toolbar-filter-by-category": "Filtrar por categoría" }
```

- Interpolación de parámetros con `{{param}}` para valores dinámicos. No concatenar strings con traducciones: el orden de las palabras cambia entre idiomas.
- Mantener claves **sincronizadas entre todos los ficheros de idioma**.
- Para cantidades, usar pluralización (plugin de mensajes de Transloco si está instalado) en lugar de claves separadas por número.

## Uso en templates

Usar la **directiva `*transloco`** como forma principal. El **pipe `| transloco`** solo para bindings de atributo o cuando la directiva no pueda aplicarse:

```html
<!-- ✅ Directiva — forma preferida para bloques de contenido -->
<ng-container *transloco="let t; read: 'toolbar'">
  <span>{{ t('filter-by-category') }}</span>
  <button type="button">{{ t('search') }}</button>
</ng-container>

<!-- ✅ Pipe — solo para atributos o bindings individuales -->
<input [attr.aria-label]="'toolbar.filter-by-category' | transloco" />
<button type="button" [title]="'common.close' | transloco">
  <i class="bi bi-x" aria-hidden="true"></i>
</button>

<!-- ❌ Evitar — pipe en contenido de texto -->
<span>{{ 'toolbar.filter-by-category' | transloco }}</span>
```

- Usar el parámetro `read` para fijar el prefijo del scope y simplificar las claves.

## Uso en TypeScript

```typescript
private readonly transloco = inject(TranslocoService);

// Síncrono — para valores puntuales cuando el idioma (y el scope) ya están cargados
const label = this.transloco.translate('toolbar.filter-by-category');

// Reactivo — se actualiza cuando cambia el idioma activo
readonly title = toSignal(this.transloco.selectTranslate('page.title'), { initialValue: '' });

// Una sola vez — esperar a que la traducción esté cargada y no seguir cambios de idioma
const once = await firstValueFrom(this.transloco.selectTranslate('page.title'));
```

- `translate()` devuelve la clave si la traducción todavía no se ha cargado: no lo uses en inicializadores tempranos ni con scopes lazy aún no cargados.
- Si el texto debe reaccionar al cambio de idioma, **no** añadas `take(1)`.
- Con SSR, el loader de traducciones se ejecuta en el servidor: las URLs relativas de los ficheros de idioma deben poder resolverse allí (ver la skill `angular-developer` (oficial)).

## Títulos de página

Definir la clave del título en el campo `title` de la ruta:

```typescript
{
  path: 'products',
  title: 'products.page-title',
  loadComponent: () => import('@pages/products/products'),
}
```

Si el proyecto tiene configurada una `TitleStrategy` basada en Transloco (ver guidelines), resolverá la clave automáticamente.

## Checklist al añadir texto

- [ ] Clave añadida en **todos** los ficheros de idioma del proyecto (ej. `es.json`, `gl.json`, según guidelines)
- [ ] Clave en kebab-case y agrupada por contexto
- [ ] Sin concatenación de fragmentos traducidos
- [ ] Template usa directiva `*transloco` (o pipe solo para atributos)
- [ ] Textos de `aria-label`, `title` y `alt` también traducidos
- [ ] Si es scope de funcionalidad: fichero en `public/i18n/<scope>/` (o en los assets de la librería, en un monorepo)
- [ ] Scope registrado con `withTranslocoScope()` en la ruta correspondiente
